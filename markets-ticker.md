# Ticker & Token List

The Ticker & Token List is the primary discovery and monitoring interface for the global market.

### Live Ticker Bar
- Real-time price updates for **4200+ tokens** and selected TradFi assets
- Aggregated across all supported exchanges
- Continuous streaming data with minimal latency

### NYSE Market Status
- Live market status badge (Open / Closed / Pre-Market / After-Hours)
- Countdown timer to the next session
- Synthesized NYSE Opening Bell that plays automatically at 9:30 AM ET

### Token List Tabs
- **Hot** — Currently most active markets
- **Gainers** — Strongest performers
- **Losers** — Weakest performers
- **Top** — Highest volume / market cap
- **Arb** — Tokens with active cross-exchange spreads
- **New** — Recently listed markets
- **Favorites** — Your personal watchlist

### Additional Features
- Price flash animations (green/red) on every tick
- Fast search and filtering
- One-click switching between tokens
