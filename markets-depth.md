# Depth

The Depth tab provides a real-time, aggregated view of order book liquidity across multiple exchanges.

---

### Key Features

- **Aggregated Order Book**  
  Combines bids and asks from up to 16+ exchanges into a single unified book.

- **Bid / Ask Pressure**  
  Clear percentage breakdown of buying vs selling pressure.

- **Total Bid & Ask Liquidity**  
  Shows total dollar depth available on each side (e.g. $351K bids vs $289K asks).

- **Visual Depth Chart**  
  Cumulative depth visualization so you can instantly see where liquidity is concentrated.

- **Depth Ratio by Distance**  
  Breakdown of bid dominance at ±1%, ±2%, and ±5% from mid price.

- **Slippage Estimator**  
  Real-time slippage calculation for order sizes ranging from $1K to $100K on both buy and sell sides.

- **Aggregated Bids & Asks Tables**  
  Detailed price level view with cumulative quantity.

All data updates continuously via WebSocket for true real-time accuracy.
