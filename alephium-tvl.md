# TVL Analytics

The TVL Analytics module provides deep insight into liquidity dynamics across Alephium pools.

---

### Core Features

- Current Total Value Locked (in both ALPH and USD)
- Long-term historical TVL charts (supporting 300+ days of data)
- All-time high and all-time performance metrics
- Pool stability and volatility indicators

---

### Advanced Insights

- Attribution of TVL changes (LP deposits & withdrawals vs price action)
- Recent LP events timeline
- Detailed daily historical data table
- Dominance and comparative metrics against broader protocol liquidity

This module helps you understand whether liquidity is expanding, contracting, or simply fluctuating with price — a critical distinction for serious participants.
