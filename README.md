# Welcome to DOH.Money

**DOH** stands for **Decentralized Open Hub**.

DOH Money is a professional-grade crypto trading terminal built for traders who demand performance, transparency, and sovereignty. Available as both a native desktop application and a web app at [app.doh.money](https://app.doh.money), it aggregates real-time data from **22 major centralized exchanges** and the **Alephium blockchain** into a single, high-density interface.

Instead of forcing you to run multiple exchange terminals, blockchain explorers, portfolio trackers, news feeds, and automation tools, DOH Money consolidates the entire workflow into one cohesive platform.

---

### The Vision

We believe the future of trading infrastructure should be open, transparent, and user-owned.  

DOH was created to serve as a true **Decentralized Open Hub** — a place where powerful tools, real-time market data, on-chain intelligence, and AI-assisted execution come together without sacrificing user control or privacy.

---

### Core Modules

#### 1. Global Crypto Markets
A professional multi-exchange terminal covering 4200+ tokens across 22 centralized exchanges.

- Live ticker bar with real-time prices
- Advanced TradingView charts
- Aggregated order books and depth charts
- Live trades feed with whale detection
- Cross-exchange arbitrage scanner
- Futures data (funding rates, open interest)
- Multi-dimensional Risk Report with live rug detection
- Real-time news, Nostr, and X/Twitter feeds
- Fully customizable sidebar with 12 modules

#### 2. Alephium Dex Screener
One of the most advanced on-chain analytics terminals available for Alephium.

- Real-time and historical transaction monitoring
- Deep TVL and liquidity analytics
- Advanced holder distribution and cluster (spider) tracking
- CEX inflow and outflow intelligence
- Institutional-grade Wallet Tracker with full P&L, portfolio analysis, and behavioral scoring

#### 3. DOH DEX
Native Alephium decentralized exchange with a professional trading interface.

- Spot trading (Market + Limit)
- Perpetual Futures (isolated margin, up to 10x)
- Liquidity provision
- Token Launchpad
- Staking
- Built-in AI Assistant
- Automated Agents (DCA, Limit, and custom strategies)

#### 4. Arbitrage Dashboard
Dedicated tools for cross-exchange opportunity detection and simulation.

- Real-time spread scanner across 22 exchanges
- Net profit modelling after fees, slippage, and latency
- Full Bot Simulator for strategy testing
