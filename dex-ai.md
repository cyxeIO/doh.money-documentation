# AI & Agents

The DOH DEX features a powerful AI layer designed to assist and automate trading directly inside the terminal.

---

### AI Assistant
- Context-aware chat interface (“Ask the desk”)
- Can analyze market conditions, liquidity, and trading ideas
- Understands the current pool, price action, and your portfolio
- Available directly in the main trading view

---

### Automated Agents

DOH supports persistent automated strategies that run on your behalf:

- **DCA Agents** — Dollar-cost average into any token on a custom schedule
- **Limit Agents** — Automated limit order execution
- **Custom Strategies** — Advanced logic (coming soon)

#### Agent Features
- Real-time status and performance tracking
- Pause / Resume / Edit controls
- Detailed execution history
- Capital and risk limits
- Runs even when the interface is closed (via backend agents)

---

### Agent Dashboard
The right panel shows all active and paused agents with:
- Current progress
- Performance metrics
- Next execution time
- Quick controls

AI and Agents turn the DOH DEX from a manual trading interface into a true intelligent trading desk.
